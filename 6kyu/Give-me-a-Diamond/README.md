## 📝 Problem Description

Create a function that returns a string representing a diamond shape made using asterisk (`*`) characters.

The diamond should:

- Have the given size `n`.
- Be centered using spaces.
- Have no trailing spaces.
- Have every line terminated with a newline character (`\n`).
- Return `null` if `n` is zero, negative, or even.

A diamond can only be created when the size is a positive odd number.
