## 📝 Problem

Create multiple functions that return the result of different mathematical operations between two numbers.

The required functions are:

- `add` → addition
- `multiply` → multiplication
- `divide` → division
- `mod` → modulus
- `exponent` → exponentiation
- `subt` → subtraction

Each operation follows the format `a (operation) b`.

### Examples

    add(10, 5) → 15
    multiply(10, 5) → 50
    divide(10, 5) → 2
    mod(10, 3) → 1
    exponent(2, 3) → 8
    subt(10, 5) → 5

---

## 💡 Approach

- Create a separate function for each mathematical operation.
- Accept two parameters, `a` and `b`.
- Apply the required JavaScript operator.
- Return the calculated result from each function.
