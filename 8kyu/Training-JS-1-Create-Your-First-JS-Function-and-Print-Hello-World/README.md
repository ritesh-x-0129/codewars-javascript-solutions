# Training JS #1: Create Your First JS Function and Print "Hello World!"

## 📌 Difficulty

**8kyu**

---

## 📝 Problem

Write your first JavaScript function named `helloWorld()`.

The function should:

- Create a variable named `str`.
- Assign the value `"Hello World!"` to it.
- Print the value using `console.log()`.

---

## 💡 Approach

1. Define a function named `helloWorld()`.
2. Create a variable `str` containing `"Hello World!"`.
3. Print the variable using `console.log()`.

---

## ⏱ Time Complexity

```text
O(1)
```

Only a constant number of operations are performed.

---

## 💾 Space Complexity

```text
O(1)
```

Only one string variable is used.

---

## 🛠 Technologies Used

- JavaScript (ES6)

---

## ✅ Example

```javascript
helloWorld();

// Output:
Hello World!
```
