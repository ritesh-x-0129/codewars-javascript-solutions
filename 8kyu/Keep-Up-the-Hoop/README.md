# Keep Up the Hoop

## 📖 Problem

Return an encouraging message based on how many times Alex keeps the hula hoop going.

### Example

```javascript
hoopCount(10); // "Great, now move on to tricks"
hoopCount(5);  // "Keep at it until you get it"
```

---

## 💡 Approach

- Check if the number of hoops is `10` or more.
- If it is, return the success message.
- Otherwise, return the encouragement message.

---

## ⏱️ Complexity

- **Time Complexity:** `O(1)`
- **Space Complexity:** `O(1)`
