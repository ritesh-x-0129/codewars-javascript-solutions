# 5 Without Numbers !!

## 📖 Problem

Write a function that always returns `5`.

### Restrictions

You **cannot** use any of the following characters:

```text
0123456789 * + - /
```

### Example

```javascript
unusualFive(); // 5
```

---

## 💡 Approach

- Create a string containing exactly five characters.
- Find the length of the string using the `length` property.
- Return the length, which is `5`.

---

## ⏱️ Complexity

- **Time Complexity:** `O(1)`
- **Space Complexity:** `O(1)`
