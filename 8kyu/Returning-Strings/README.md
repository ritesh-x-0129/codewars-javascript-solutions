# 👋 Returning Strings

## 📌 Difficulty

**8kyu**

---

## 📝 Problem

Create a function that accepts a name as a parameter and returns the message:

    "Hello, <name> how are you doing today?"

The returned string must match the required format exactly.

### Examples

    greet("Florence Pugh") → "Hello, Florence Pugh how are you doing today?"

---

## 💡 Approach

- Create a function named `greet` that accepts `name` as a parameter.
- Use a template literal to insert the given name into the required string.
- Return the formatted greeting.
